# Room: Careers in Cyber Security
**Path:** Pre Security / Introduction to Cyber Security
**Date:** July 2026
**Difficulty:** Easy

## Objective
Learn about the main career paths in cyber security, understand the difference between offensive and defensive security roles, and explore common job responsibilities and career progression.

## Key Concepts

- **Cyber Security Careers:** Cyber security offers many career paths with high demand, competitive salaries, and continuous learning opportunities.
- **Blue Team:** Defenders responsible for protecting an organization's systems, networks, and users.
- **Red Team:** Offensive security professionals who simulate real-world attacks to identify weaknesses before attackers do.
- **Engagement:** A formal agreement between a company and a penetration tester that defines the scope and rules of an authorized security assessment.

## Roles Covered

### Security Analyst (Blue Team)
Security Analysts monitor an organization's devices and network, investigate suspicious activity, and respond to security incidents.

**Typical Responsibilities**
- Monitor network and endpoint activity.
- Investigate suspicious events and alerts.
- Analyze security incidents.
- Work with other teams to strengthen security.

**Example**
An employee who normally works in London suddenly logs in from another country. The analyst investigates whether the login is legitimate or an account compromise.

**Career Progression**
- Threat Hunting
- Incident Response
- Malware Analysis

---

### Security Engineer (Blue Team)
Security Engineers design, build, and maintain security systems that protect an organization's infrastructure.

**Typical Responsibilities**
- Design and maintain security solutions.
- Manage tools such as Intrusion Detection Systems (IDS).
- Assess risks and vulnerabilities.
- Document security processes.
- Stay updated with new attack techniques.

**Example**
Maintaining an Intrusion Detection System (IDS), which monitors network activity and detects potential attacks.

**Career Progression**
- Application Security
- Cloud Security
- Can transition into Offensive Security roles

---

### Penetration Tester (Red Team)
Also known as an Ethical Hacker, a Penetration Tester legally attempts to exploit vulnerabilities to evaluate an organization's security.

**Typical Responsibilities**
- Test networks, systems, and web applications.
- Perform security assessments and audits.
- Exploit vulnerabilities in a controlled environment.
- Write reports explaining findings and remediation steps.

**Important**
All testing is performed with the organization's permission under a defined engagement.

**Career Progression**
- Network Penetration Testing
- Web Application Penetration Testing
- Red Teaming (advanced offensive security)

## Terms Learned

- **IDS (Intrusion Detection System):** A security system that monitors network or system activity to detect suspicious or malicious behavior.
- **Alert:** A notification generated when suspicious activity is detected.
- **Threat Hunting:** Proactively searching for hidden threats that may have bypassed automated security tools.
- **Incident Response:** Handling and containing active cyber attacks.
- **Malware Analysis:** Studying malicious software to understand how it works and how to defend against it.

## What I Learned

Cyber security is much broader than just hacking. It includes both defensive roles, such as Security Analysts and Security Engineers, who protect organizations, and offensive roles, such as Penetration Testers, who safely simulate attacks to identify vulnerabilities before malicious attackers can exploit them. Each role has different responsibilities but contributes to improving an organization's overall security posture.
